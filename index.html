01 / 知象 / 经营数据

MIRACO 2认缴约95.12万美元

11月20日读取 · Kickstarter全球项目 · 第三方跟踪数据

Kicktraq本次显示认缴951,213美元、533名支持者。相比昨日更新版的821,885美元、458人，增加129,328美元及75人；两次读取并非严格间隔24小时。

项目11月18日启动，计划1月8日结束。这是认缴意向，不是到账收入或交付量；未与Kickstarter原平台统计交叉核对。搜索摘要仍可能显示更旧数字，本期采用直接打开页面的数据。

商业判断：需求继续增加，尚不支持按首日速度外推最终金额。更值得观察优惠档位结束后的新增认购。

02 / 先临 / 软件入口

EXStar Mobile更新iOS下载状态，GO的真实UI口碑仍待积累

官方支持页更新：11月19日16:03（页面标注时间，未注明时区）

官方支持页现标注EXStar Mobile已可在App Store获取：Android版1.1.0-16，iOS版1.1.0-14。该应用支持EZ GO、Rockit及EINSTAR 2；Android更新说明包括EZ GO适配、向PC传输优化和稳定性改进。

你关心的GO UI：本期未找到足够可核实、由独立用户给出的EZ GO具体界面评价。不能把官网“易用”文案或Rockit的问题当成GO用户口碑。

后续重点：首次连接是否清楚，扫描状态与跟踪丢失提示是否有帮助，后处理和导出是否好找。官方入口变化可核实，使用体验仍需真实用户反馈。

03 / Meshy / API商业化

四足绑定与动画上线，收费与双足保持一致

11月18日更新 · 近7日补充

Meshy API增加四足动物绑定，并提供行走、奔跑动画。官方说明四足绑定及每条动画的积分费用与双足一致，没有披露这项功能的收入或付费用户。

商业判断：付费范围从生成模型延伸到可用角色资产，有机会增加一次创作中的付费环节；是否带来收入增量仍未披露。

来源：Meshy官方更新日志

04 / Tripo / API工作流

默认纹理版本升级到V3.5

公告11月11日 · 11月16日起执行 · 本期首次收录

Tripo开发者公告称，API默认纹理版本从V3.0升级到V3.5。接入方需要关注同样输入的视觉输出是否改变；公告不构成销量或收入增长证据。

Tripo多篇旧月报当前显示11月19日“更新”，不能据此把其中所有功能写成昨日新发布。

业务判断：批量生产资产应记录模型/纹理版本，避免默认版本变化让验收标准和历史结果不一致。

05 / 用户的声音 / 交互与使用

让提示可理解，让编辑结果符合预期

11月20日整理 · 历史案例补充 · 两帖来自同一用户，不算独立共性证据

EXStar Mobile 1.1.0-16 / Rockit / Pixel 9 Pro Fold

“提醒内存风险”还是“禁止继续扫描”？

11月12—13日的帖子中，用户报告新版应用在启动扫描时因内存提示停止，旧版1.0.0-55曾可继续。支持人员解释新版增加内存检查以减少崩溃和数据丢失，并指出该Pixel机型的Tensor芯片不在已测试设备名单。

用户认为应提供警告，而不是直接拒绝扫描。其自行调整后台服务的办法未经本期验证，不作为操作建议。

UI启示：阻断提示应解释触发原因、兼容性和恢复路径。这是Rockit体验，不是EZ GO实测。

原帖及支持回复

EXStar Hub 2.1.0-10 / Rockit / 全局标记点

删除标记后仍参与跟踪，用户给出临时办法

11月13日发帖、17日补充：用户称删掉转台标记后，继续扫描时仍受这些点影响；保存P3文件、建新项目重新导入后，则可按编辑后的标记扫描。支持人员要求录屏以复现，没有读取到正式修复结论。

交互启示：“已删除”的显示状态，需要与实际跟踪状态一致。单个用户报告，尚未独立复现。

原帖及临时处理流程

06 / 论文 / 三维高斯

CrossPressor：减少长序列的跨视图融合开销

11月4日提交 · 历史阅读 · arXiv标注WACV 2027接收

完整标题：CrossPressor: Scalable Cross-View Fusion for Feed-Forward 3D Gaussian Splatting。

作者单位：Yuxi Hu、Jun Zhang、Friedrich Fraundorfer——奥地利格拉茨工业大学；Wenhao Dong——比利时根特大学。

通过覆盖引导的证据路由，在保留解码器锚点查询的同时限制支持视图序列开销，无需重新训练。作者报告长序列跨视图融合最高加速26.12倍，端到端加速1.43倍；不能把前者当作完整建模速度。

价值与限制：适合关注多视图重建的算力成本，依赖具体锚点融合架构，收益不是普适保证。本次未确认代码权重已开放，未复现。

来源：论文及方法

07 / 论文 / 三维补全

LaS-Comp：先保留已知几何，再细化补全边界

2月21日提交、3月18日修订 · 历史阅读 · CVPR 2026

完整标题：LaS-Comp: Zero-shot 3D Completion with Latent–Spatial Consistency。

作者单位：Weilong Yan、Yihao Ai——新加坡国立大学；Haipeng Li、Shuaicheng Liu——电子科技大学；Hao Xu、Jingyu Hu——香港中文大学；Nianjin Ye——Changhong Intelligent Robot。

利用三维基础模型先验，先用显式替换保留部分观测几何，再用隐式细化改善已知与生成区域的接缝。无需训练新的补全模型，支持文字或图像条件。

价值与限制：与扫描缺失补全直接相关，但保留机制仍需在你的扫描数据上验证，不能等同于工业尺寸精度。官方仓库已有代码、环境和推理说明；依赖基础模型权重及CUDA组件，本次未复现。
